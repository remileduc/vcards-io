@vcards-io/jscontact
====================

JSContact 2.0 (RFC 9553/9982) types, validator, JSON Pointer/PatchObject utilities and structured diff

Status: milestone 3 under way. The types, the enumerated values, the
vendor extensions, JSON Pointer, PatchObject, localization and the
utilities are there; the validator and the JSON reader are not yet, and no
export is frozen before them. See `docs/plan.md` at the repository root.
